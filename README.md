# Карта камер

Локальное приложение для загрузки карты, размещения камер и прокладки кабелей. Поддерживаются PNG/JPG, масштабирование, камеры с горизонтальным сектором обзора, столбы, точки крепления, шкафы и сохранение всей схемы в файл проекта.

## Запуск в Windows

1. Откройте папку проекта в Проводнике.
2. Дважды щёлкните по файлу `index.html`.
3. Если Windows спросит, чем открыть файл, выберите Microsoft Edge, Google Chrome или Firefox.

Установка, интернет и локальный сервер не нужны. Выбранная картинка читается браузером напрямую с компьютера и никуда не отправляется.

## Проекты

- **Новый** — очистить редактор и начать новый проект. Если текущие изменения не сохранены, приложение предупредит об этом.
- **Открыть проект** — выбрать ранее сохранённый файл `.cmap`.
- **Сохранить** — скачать самодостаточный файл проекта в стандартную папку загрузок браузера.
- В `.cmap` хранится сама картинка карты, все объекты, оборудование шкафов, кабельные маршруты, размеры элементов и положения карточек.
- Красная точка и надпись **«не сохранён»** рядом с названием проекта означают, что после последнего сохранения были изменения.
- При закрытии вкладки с несохранёнными изменениями браузер показывает предупреждение.

Файл `.cmap` можно перенести на другой компьютер и открыть в этом же приложении: отдельно прикладывать исходную картинку не требуется.

## Управление

- **Загрузить карту** — выбрать файл PNG, JPG или JPEG.
- **Колесо мыши** — изменить масштаб относительно курсора.
- **Левая кнопка мыши + перемещение** — сдвинуть карту.
- **Показать целиком** — вписать всю карту в рабочую область.
- **Размер элементов** — одновременно настроить размер значков камер, креплений и шкафов относительно карты.
- **Камера** — включить добавление, затем щёлкнуть по нужному месту карты.
- **Столб** и **Точка крепления** — добавить опору для одной или нескольких камер.
- **Шкаф** — добавить конечную точку кабельного маршрута.
- Двойной щелчок по шкафу открывает его отдельную карточку поверх карты.
- Карточки нескольких шкафов можно открыть одновременно, перемещать за заголовок, сворачивать и закрывать.
- Пунктирная линия связывает карточку с соответствующим шкафом.
- Общий ползунок **Размер элементов** меняет также масштаб карточек шкафов.
- Ширина каждой карточки изменяется перетаскиванием её правой границы; двойной щелчок по границе возвращает стандартную ширину.
- В карточку можно добавить Wi-Fi-роутер, коммутатор, PoE-коммутатор, видеорегистратор, оптический кросс, оптическое или другое оборудование.
- Для оборудования можно указать название, модель, необязательный IP-адрес, количество портов и примечание.
- **Кабель** — выбрать источник, промежуточные опоры и конечный шкаф. Для линии между шкафами приложение предложит выбрать оптику или витую пару.
- **Добавить камеру** в свойствах крепления — выбрать свободную камеру или поставить новую в её фактическое место.
- **Значок камеры** — выбрать или перетащить камеру.
- При наведении на камеру показываются её название, модель и IP-адрес.
- Перетаскивание камеры к креплению привязывает её; связь показывается пунктиром при выборе.
- Перемещение крепления переносит связанные камеры с сохранением их расположения.
- **Круглый оранжевый маркер** — изменить направление камеры.
- **Бело-синий маркер** — изменить длину обзора камеры вдоль её направления.
- **Горизонтальный угол** — изменить ширину сектора в свойствах выбранной камеры.
- **Длина обзора** — задать дальность сектора в процентах от короткой стороны карты.
- **ОК** — закончить редактирование и снять выбор с камеры.
- Список **На карте** — выбрать ранее добавленную камеру по названию или IP.
- Выбор в списке подсвечивает объект на карте и возвращает его в видимую область, если требуется.

## Кабели

- Маршрут от камеры до шкафа создаётся как чёрная **витая пара уличная**.
- Маршрут между шкафами может быть жёлтым **оптоволокном** или чёрной **витой парой** — тип выбирается после первого шкафа.
- После выбора источника щёлкайте по столбам и точкам крепления в порядке прохождения кабеля, затем по конечному шкафу.
- Общие участки нескольких кабелей отображаются параллельно с постоянным расстоянием на экране.
- **Escape** отменяет незавершённый маршрут.
- **Delete** — удалить выбранную камеру, если курсор не находится в поле ввода.
- **Escape** — отменить добавление камеры.
