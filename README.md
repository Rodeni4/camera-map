# Редактор карты камер

Локальное приложение для размещения камер, прокладки кабелей, учёта оборудования и схем подключения узлов. Откройте `index.html` в современном браузере. Установка и сервер не требуются.

## Проект и карта

- Загрузите карту в формате PNG или JPG.
- Колесо мыши меняет масштаб, перетаскивание фона перемещает карту.
- Кнопка «Показать целиком» возвращает всю карту в рабочую область.
- «Размер элементов» меняет размер значков камер, столбов и узлов.
- Проект сохраняется в `.cmap`, включая карту, оборудование, фотографии, кабели, соединения, состояния камер и выбранный вид карты.
- При повторном открытии восстанавливаются приближение и положение карты. Старые проекты без сохранённого вида открываются целиком.
- Каждое нажатие «Сохранить» открывает выбор имени и папки с текущим именем проекта: можно заменить файл или сохранить отдельную копию. В браузерах без поддержки этого окна файл скачивается стандартным способом.
- Ctrl+Z — отменить действие, Ctrl+Y или Ctrl+Shift+Z — повторить. В полях ввода действуют стандартные команды редактирования текста.

## Камеры и столбы

- Выберите «Камера», «Столб» или «Узел», затем щёлкните на карте.
- Значок камеры можно перетащить. Оранжевый маркер меняет направление, синий — длину обзора.
- В свойствах камеры задаются название, модель, IP, MAC, угол и длина обзора.
- Состояние определяет цвет камеры: зелёный — активна, красный — авария, жёлтый — проблемная, чёрный — выключена, серый — демонтирована.
- Перетаскивание камеры к столбу привязывает её. При перемещении столба камеры перемещаются вместе с ним. Отвязка доступна в свойствах камеры.
- Названия камер включаются кнопкой с глазом; выбранный режим сохраняется.
- Окно свойств камеры, столба, узла или кабеля можно переместить за заголовок. Положение сохраняется при выборе других объектов в текущем сеансе; окно остаётся внутри рабочей области.
- Выберите объект и нажмите Delete для удаления. Клавиши в полях ввода и диалогах не удаляют объекты карты.
- Создание отдельных точек крепления убрано. Точки из старых проектов продолжают загружаться и работать.

## Кабели

- Выберите «Кабель». Первый клик задаёт начало, следующие — повороты маршрута.
- Кабель можно начать в свободной точке, на камере или узле. От камеры прокладывается витая пара; при начале от узла предлагается витая пара или оптика.
- Клик по конечному узлу, двойной клик по карте или Enter завершает маршрут по зафиксированным точкам.
- Esc убирает последнюю вершину; когда вершин не осталось, отменяет рисование.
- Выделите готовый кабель, чтобы перетаскивать его свободные вершины.
- Для привязки готовой линии перетащите её свободное начало или свободный конец к камере либо узлу. Привязанная линия следует за объектом. Оптика привязывается только к узлам.
- Кабели одного типа на общем участке объединяются в пучок; щелчок позволяет выбрать нужный кабель.
- Во вкладке «Оборудование» для кабелей задаются тип свободным текстом и длина в метрах. У витой пары дополнительно выбирается уличная или внутренняя прокладка.

## Схемы узлов

- Двойной клик по узлу или кнопка «Схема подключений» открывает отдельную вкладку.
- «Добавить оборудование» добавляет устройство непосредственно в схему.
- Один клик выбирает любой блок: камеру, соседний узел или устройство. Рядом с «Отменить выбор» появляется соответствующая кнопка удаления. Удаление камеры или узла удаляет сам объект и связанные кабели после подтверждения.
- Двойной клик по любому блоку или Enter на нём открывает вкладку «Оборудование», прокручивает к строке объекта и ставит курсор в его описание. Поиск при переходе очищается. Для свободной точки маршрута открывается строка кабеля.
- Удаление устройства очищает его соединения, сохраняя остальные устройства и кабельные маршруты.
- Блоки перемещаются за заголовок. Колесо меняет масштаб схемы, перетаскивание фона перемещает её.
- Для соединения выберите кабель и порт устройства либо два порта. Занятый порт нельзя назначить второй связи.
- Выбранную связь можно удалить кнопкой в панели схемы. При уменьшении количества портов недействительные соединения очищаются.
- Свободный порт серый, подключённый — зелёный. Выберите порт и нажмите «Отметить неисправным» в панели схемы: он станет красным. «Снять неисправность» возвращает автоматический цвет, сохраняя соединение. Отметки сохраняются в проекте и отображаются в PDF.

## Перечень оборудования и PDF

- Во вкладке «Оборудование» собраны камеры, узлы, устройства, столбы и кабели. Данные редактируются прямо в таблицах; доступны поиск и фотографии.
- Для камер не показывается расположение; для узлов не показываются расположение, модель, IP и порты.
- «Сохранить в PDF» открывает печать: текущая видимая область карты, полный перечень оборудования и отдельный лист для схемы каждого узла.
- Каждая схема целиком масштабируется под один лист; перечень при необходимости занимает несколько страниц.
- Формат — A4, альбомная ориентация, поля 5 мм. В диалоге браузера выберите сохранение в PDF и масштаб 100%. Для чистого листа отключите браузерные колонтитулы.
